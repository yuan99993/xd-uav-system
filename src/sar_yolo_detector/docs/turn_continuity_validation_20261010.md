# 转弯连续性修正与验证

范围：实验正式方案的 `sar_yolo_detector`。未修改 `xd_uav_track`、train7权重、消息和服务定义。

## 修正

1. 多目标LK从仅平移检验改为有界相似变换，保留前后向误差、有效点数、运动一致性、位移及TTL门控。
2. 保留受目标特征支撑的足迹，避免重复旋转AABB导致框扩大。部分出画时，仅在有效特征充足时裁剪输出；完全出画仍丢失。
3. 当前帧独立LK证据与新YOLO结果分开保存，最多30个默认tracklet、无图像副本。新检测不再覆盖已算好的视觉证据。
4. 选中目标可在KCF失败时使用同ID、当前帧且通过外观/位置/尺度/时间门控的LK证据；不能用它绑定新身份或刷新真实检测时间。
5. 长车转向的尺度门控采用已验证足迹的面积比；相机旋转也不再将AABB扩张误学成真实面积增加。
6. 颜色支撑充足时，外观直方图排除低饱和地面。灰白目标保留全ROI回退；此线索仍不是深度ReID。
7. 一帧KCF失败后，强门控通过的同ID、新鲜检测可直接恢复；新ID、长失联、竞争/歧义仍需连续确认。
8. 从可信当前检测周期性刷新KCF模板，周期性刷新间隔为0.75秒，避免旧模板持续到转弯时突然失败。
   原有漂移/故障修复仍可另外重初始化；这些操作均不重建公开身份。

## 回归

- 新增双目标旋转序列：31帧、每步7°，目标间隔检测5帧；选中目标KCF人为失效，后续检测置信度0.2。
  两条光流轨迹保持连续，选中公共ID保持99，实测辅助框与合成真值IoU均大于0.70。
  旧实现在首次7°旋转时因`non_rigid_or_inconsistent_flow`丢掉两条轨迹；修正后通过。
- 部分出画、当前弱检测覆盖LK、错误ID/位置/尺度、TTL、歧义、重获、原帧点击/ROI、显示/数值一致性均回归。
- 算法/ROS适配/原PixEagle和手动模式等145项通过，无跳过；另9项PNG网页测试在网页实际使用的系统Python中通过。
- GPU推理虚拟环境的cv_bridge动态库与系统存在libffi冲突，因此PNG测试使用系统Python，不把环境错误算作通过。
  推理节点自身使用已有图像编解码路径；网页节点实际也使用系统Python。

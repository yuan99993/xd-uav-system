# 快速目标锁定与验证方案

2026-11-19 的 UE＋PX4 复测中，车辆和无人机在运动前均已建立可信锁定。车辆运动段正确率为 2.1%，首次失锁后直到测试结束都未恢复。无人机正确率为 16.9%，469 条被标记为有效的状态中有 410 条未通过投影核验。已有严格像素复核候选未通过起动前验收，失败时目标与附近背景的匹配代价过于接近。

## 第一轮算法对照

- 全图 D-FINE 保留候选发现及失锁后的广域搜索。局部跟踪继续独立运行，用原始帧时间和相机姿态提交候选框。局部窗口内比较前景复核和当前默认算法，候选位置、像素验证及框坐标使用同一帧。
- 以选中帧的前景像素作身份参考。把候选周围和相似干扰区域作为负样本，比较前景结构及邻域背景差异。记录正确匹配与最强干扰的分数差，按目标尺寸、纹理和背景分桶，避免仅通过调低拒绝阈值获得更多有效状态。
- 比较原分辨率 ROI 内的小目标检测与前景结构匹配。检测作为独立的当帧证据，同时记录裁剪坐标还原误差、分类分数、背景误检和额外 P95 处理开销。对同一段 RGB、同一初始 ROI 固定检测和局部跟踪基线。
- 失去独立像素支持即退出当前有效锁定。以最近一次可信位置、像素速度和相机运动提供有界搜索窗口，几帧内未确认则回到全图候选。只有同一身份通过连续新帧验证，才恢复有效锁定并测量重捕耗时。

## 实景验收

先在固定 90° 的场景对照静止、低速、快速、同类干扰和定时遮挡或移出画面的条件。每组至少重复三次。静止阶段用连续的新鲜观测验证初始化，运动开始后不重选目标。真值仅用于评分与起动资格检查。

- 给定初框后，可见且正确的状态比例至少 90%，有效观测最长间隔不超过 0.5 秒，已确认目标 ID 切换为零。
- 单列错误有效状态占比、目标不可见时的有效状态数及检测框漂移。候选目标暂定错误有效比例不超过 1%，目标明确不在画面时有效状态数为零。
- 对预设遮挡记录遮挡结束至同一身份首次重新确认的时间，列出每次结果与未恢复次数；足够重复后再计算 P95。自然往返中观测消失至恢复的时间包含不可见窗口，另行报告。
- 记录曝光或采集到 ROS、解码、局部跟踪、独立复核、有效观测与云台命令应用的时序分位数。浏览器测绘制时帧龄，模型自动发现另用带标注的无叠框原始视频评分。

通过移动目标对照后，再比较压缩质量对动态小目标的影响。改变视场角与模型权重各自作为独立变量。

# FloodNet SegFormer-B0 pilot training record

Date: 2026-08-17  
Profile: `floodnet_segformer_b0_pilot_10e`  
Status: completed normally, 10/10 epochs

## Reproducibility

- Dataset: FloodNet Supervised v1.0, official split: 1,445 train / 450
  validation / 448 test images.
- Input: RGB image and grayscale class-index mask, random 1024×1024 train crop,
  fixed centre 1024×1024 validation crop.
- Model: `nvidia/mit-b0` encoder with a 10-class SegFormer semantic head.
- Loss: median-frequency capped weighted cross entropy plus 0.5 Dice loss.
- Optimizer: AdamW; backbone learning rate `6e-5`, decoder learning rate
  `6e-4`, weight decay `0.01`.
- Batch: physical micro-batch `1`, 12-step gradient accumulation, effective
  batch `12`. This was selected from a real 1024×1024 forward/backward memory
  probe: batch 1 peaked at about 2.62 GiB allocated, while batch 2 exceeded the
  4 GiB GPU budget.
- Device: NVIDIA GeForce RTX 3050 Laptop GPU, CUDA PyTorch `2.4.1+cu121`.
- Mixed precision: enabled. Gradient checkpointing: unavailable in the
  installed Hugging Face SegFormer semantic implementation and therefore
  explicitly disabled.
- Total recorded epoch time: approximately 7,184 seconds (about 2.0 hours).

## Assessment

The pilot learned water and flooded-building regions reasonably well and
improved steadily over the first four epochs. The final mIoU gain over epoch 1
was about `+0.131`. Flooded-road segmentation is still weak and variable across
epochs; it must be improved before an automatic road-flood mission cue is
trusted. Mean IoU is also depressed by the near-zero background score in this
fixed centre-crop evaluation, so the next comparison must include full tiled
validation and event/region metrics.

This result is a research baseline, not an operational model. The saved
checkpoint is not yet an ONNX/TensorRT engine, and the C++ ROS node still
requires a separate inference node to publish a timestamped MONO8 class mask.
No flight command, Tracker/Follower command, or map task point is generated by
this checkpoint alone.

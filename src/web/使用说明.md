# 固定翼任务 Web 使用说明

本文是 `src/web` 唯一需要提交的操作说明。命令默认从仓库根目录
`/home/promise/catkin_ws/src/xd-uavsystem-test` 执行。

## 页面和功能

- `http://127.0.0.1:5173/`：原单机地形规划页。搜索位置、加载在线 DEM，
  设置起终点并生成 RRT* + Dubins Airplane 三维预览航线。
- `http://127.0.0.1:5173/swarm.html`：固定翼集群任务控制台。可在无 ROS
  时离线编排和检查任务；ROS 仿真在线后可创建飞机、下发任务、起飞和降落。

两个页面共用 Web 服务，但业务状态相互独立。单机页生成的 Python 预览路线
不会自动下发给 ROS；集群控制台在“离线编排”下也不会控制 Gazebo 飞机。

## 首次准备

启动脚本只检查依赖，不会自动安装。首次使用且环境不存在时，在 `src/web`
目录执行：

```bash
CONDARC="$PWD/.condarc" conda env create -f environment.yml
conda run -n terrain-nav-web npm --prefix frontend ci
```

本机已有 `terrain-nav-web` 环境时不需要重复执行。不要把 Conda 环境、
`node_modules`、`dist`、缓存或日志提交到 Git。

两个 Web 页面与 ROS 默认共用仓库已跟踪的规范地形文件
`src/terrain-navigation/resources/davosdorf.tif`。被忽略的
`src/web/terrain-navigation` 历史交接副本不参与运行，也不需要复制或恢复。

## 只启动 Web

无需 ROS、PX4 或 Gazebo：

```bash
scripts/fixedwing_mission.sh web start
```

查看状态和日志：

```bash
scripts/fixedwing_mission.sh web status
scripts/fixedwing_mission.sh web logs
```

此模式可使用原单机规划页，也可在集群控制台进行离线任务编排。

## 启动 Web 和 Gazebo 仿真

一次启动 Web、ROS/PX4 和带界面的 Gazebo：

```bash
scripts/fixedwing_mission.sh start --gui
```

也可以保持 Web 运行，再单独启动执行系统：

```bash
scripts/fixedwing_mission.sh sim start --gui
```

Gazebo 相机跟随指定飞机：

```bash
scripts/fixedwing_mission.sh view uav1
```

把 `uav1` 换成当前在线的飞机名称。

## 一条命令全部停止

无论是组合启动还是分开启动，日常退出只执行：

```bash
scripts/fixedwing_mission.sh stop
```

该命令先请求在线飞机安全降落并停止 ROS/PX4/Gazebo，再停止 Web 前后端。
停止过程可能需要数秒。以下分项命令仅用于排障，不是正常退出必需步骤：

```bash
scripts/fixedwing_mission.sh sim stop
scripts/fixedwing_mission.sh web stop
```

## 原单机地形规划页操作

1. 打开 `/`，输入地名或“经度,纬度”并点击“跳转”。
2. 初次验证建议选择 `1 km` 或 `5 km`，等待地形状态显示瓦片信息和海拔范围。
3. 选择“设置起点”，在覆盖范围内点地图；再选择“设置终点”并点地图。
4. 按需调整离地高度、安全余量、规划时间和盘旋方向。
5. 点击“3D 规划（地形跟随）”。成功后可以切换“3D 视图”。

在线 DEM 成功载入前，规划和 3D 按钮保持禁用。卫星底图与 DEM 是不同数据源，
底图可见不代表高程瓦片一定可达。

常见提示：

- `高程瓦片加载失败`：后端无法从在线 DEM 数据源取得有效 PNG，优先检查网络、
  代理、防火墙和后端日志。
- `高程矩阵全部为无数据点`：瓦片已进入浏览器，但解码结果没有有效高程；记录
  位置、覆盖范围和日志，不要继续使用该地形规划。
- `地形尚未就绪`：等待当前地形加载完成后再规划。重新搜索或改变范围会使旧地形
  立即失效，避免误用上一次路线。
- 3D 按钮不可用：当前还没有成功生成地形栅格，先解决同页显示的地形错误。

## 集群任务控制台操作

无仿真时保持“离线编排”，可检查页面交互：

1. 点击“选择 uavN 起点”，再在地图选择出生位置。
2. 创建飞机，为飞机新建任务并在地图设置航点。
3. 点击“检查任务”，查看规划与冲突检查结果。

执行真实仿真时：

1. 用 `scripts/fixedwing_mission.sh start --gui` 启动系统。
2. 打开 `/swarm.html`，确认页面显示 ROS 可连接，再主动切换到“ROS 执行”。
3. 选择出生位置并创建飞机；为每架飞机建立任务。
4. 点击“下发并规划”，等待每架飞机显示规划就绪且安全检查通过。
5. 点击“一键解锁并起飞”。需要观察某架飞机时执行相机跟随命令。
6. 点击“一键安全降落”后，以“已落地、未解锁”为完成标准；固定翼建立进近时
   仍会继续飞行一段时间。

Web 检测到后来启动的 ROS 时不会自动切换模式，也不会补发旧任务，必须由操作者
主动切换并重新下发。Gazebo Classic 不支持运行中可靠地逐架热删除；全部飞机落地
并上锁后，可使用页面的安全重启功能清空实例。

## 状态与排障

同时查看 Web 和仿真状态：

```bash
scripts/fixedwing_mission.sh status
```

同时查看两部分日志：

```bash
scripts/fixedwing_mission.sh logs
```

Web 运行文件默认位于 `/tmp/xd-uav-fixedwing-mission-web-$UID/`，仿真运行文件
默认位于 `/tmp/xd_uav_terrain_swarm_sitl_$UID/`。这些都是本机临时运行产物，
不提交 Git。
